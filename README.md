**LUMIT Trade** — это современная, высокотехнологичная платформа для торговли бинарными опционами с упором на премиальный пользовательский опыт (UX/UI), интерактивные торговые комнаты и глубокую математическую модель анализа рынка.

---

## 🎨 Визуальный стиль и Интерфейс

Интерфейс платформы разработан по канонам современных финтех-гигантов:
* **Glassmorphism Effect:** Матовое стекло с saturation 180% для создания эффекта глубины.
* **Ambient Glow:** Живой динамический фон с плавающими неоновыми сферами.
* **Apple Dark Mode Style:** Глубокие черные тона (`#000000`) для снижения нагрузки на глаза трейдера.

## 🧠 Технологический стек и Архитектура

### Frontend
* **UI-Core:** Pure HTML5 / Advanced CSS3 (Custom Variables, Keyframe Animations)
* **Fonts:** Inter (Apple Ecosystem Standard)
* **Graphics:** Vector SVG

### Core Backend & R&D (В разработке)
* **Market Dynamics:** Моделирование движения цен на основе геометрического броуновского движения (GBM).
* **Risk Management:** Система динамического изменения процента выплат (Payout) для защиты ликвидности платформы.
* **Market Sentiment Engine:** Агрегатор открытых позиций (UP/DOWN) в реальном времени.
