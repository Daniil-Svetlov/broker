# quotes-service (Go)

Микросервис котировок — go-порт прежнего `quotes.py`. Тянет реальные форекс-курсы
онлайн, считает кросс-курсы, держит «живую» цену в памяти и отдаёт её по HTTP;
параллельно пишет историю котировок в Postgres.

## Зачем «живые тики»

`open.er-api.com` обновляет курсы **раз в сутки** — за время жизни бинарного
опциона реальная цена не сдвинется. Поэтому сервис берёт реальный базовый курс
и накладывает на него микро-тики, как делал JS-движок. Получается настоящая
онлайн-цена, которая при этом двигается, и сделки честно резолвятся в WIN/LOSS.

## Модель цены (`internal/market`)

Тик считается алгоритмом `market.CalculateNextPrice`: дрейф по направлению
тренда (UP/DOWN/FLAT) + случайный шум, защитный барьер `MinPrice` и округление
до `Precision` знаков (5 для форекса, 3 для пар к JPY). Тренд держится несколько
тиков и изредка меняется (`RollTrend`, вероятность — `TREND_CHANGE_CHANCE`) с
лёгким возвратом к реальному базовому курсу, чтобы цена не уходила далеко.

## Генератор цен в консоль (`cmd/pricegen`)

Standalone-утилита: непрерывно печатает котировки по той же модели, без БД и сети.

```bash
go run ./cmd/pricegen                                  # форекс-пары, тик 1с
go run ./cmd/pricegen -symbol BTC/USD -price 65000 -precision 2 -vol 0.002
go run ./cmd/pricegen -interval 200ms -ticks 50        # быстро и конечно
```

## Расчёт курса (порт get_pair_rate)

Провайдер отдаёт курсы к USD. Дальше:

| Пара     | Формула              |
|----------|----------------------|
| USD/X    | `rate[X]`            |
| X/USD    | `1 / rate[X]`        |
| X/Y      | `rate[X] / rate[Y]`  |

## HTTP API

| Метод | Путь                       | Ответ                                            |
|-------|----------------------------|--------------------------------------------------|
| GET   | `/health`                  | `{"status":"ok"}`                                |
| GET   | `/price?symbol=EUR/USD`    | `{symbol,bid,ask,mid,timestamp}` (404 если нет)  |
| GET   | `/prices`                  | массив всех живых котировок                       |

Django берёт цену для открытия/закрытия сделки именно из `/price`.

## Запуск

```bash
# демон: онлайн-курсы + живые тики + HTTP API + запись истории в БД
go run ./cmd/quotes

# создать валютные пары в БД и выйти (порт init_assets.py)
go run ./cmd/quotes -init

# один прогон записи котировок и выход (для cron)
go run ./cmd/quotes -once
```

## Конфигурация (env)

См. `.env.example`. Ключевое: `DB_*` — Postgres, `HTTP_ADDR` — адрес API,
`RATES_API_URL` — провайдер курсов, `TICK_VOLATILITY`/`SPREAD` — параметры
симуляции, `*_INTERVAL` — периоды фоновых задач.
