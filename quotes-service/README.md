# quotes-service (Go)

Микросервис котировок — go-порт прежнего `quotes.py`. Тянет реальные форекс-курсы
онлайн, считает кросс-курсы, держит «живую» цену в памяти и отдаёт её по HTTP;
параллельно пишет историю котировок в Postgres.

## Зачем «живые тики»

`open.er-api.com` обновляет курсы **раз в сутки** — за время жизни бинарного
опциона реальная цена не сдвинется. Поэтому сервис берёт реальный базовый курс
и накладывает на него микро-тики (случайное блуждание с возвратом к базе), как
делал JS-движок. Получается настоящая онлайн-цена, которая при этом двигается,
и сделки честно резолвятся в WIN/LOSS.

## Расчёт курса (порт get_pair_rate)

Провайдер отдаёт курсы к USD. Дальше:

| Пара     | Формула              |
|----------|----------------------|
| USD/X    | `rate[X]`            |
| X/USD    | `1 / rate[X]`        |
| X/Y      | `rate[X] / rate[Y]`  |

## HTTP API

| Метод | Путь                       | Ответ                                            |
|-------|----------------------------|--------------------------------------------------|
| GET   | `/health`                  | `{"status":"ok"}`                                |
| GET   | `/price?symbol=EUR/USD`    | `{symbol,bid,ask,mid,timestamp}` (404 если нет)  |
| GET   | `/prices`                  | массив всех живых котировок                       |

Django берёт цену для открытия/закрытия сделки именно из `/price`.

## Запуск

```bash
# демон: онлайн-курсы + живые тики + HTTP API + запись истории в БД
go run ./cmd/quotes

# создать валютные пары в БД и выйти (порт init_assets.py)
go run ./cmd/quotes -init

# один прогон записи котировок и выход (для cron)
go run ./cmd/quotes -once
```

## Конфигурация (env)

См. `.env.example`. Ключевое: `DB_*` — Postgres, `HTTP_ADDR` — адрес API,
`RATES_API_URL` — провайдер курсов, `TICK_VOLATILITY`/`SPREAD` — параметры
симуляции, `*_INTERVAL` — периоды фоновых задач.
